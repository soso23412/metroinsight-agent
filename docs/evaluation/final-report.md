# v0.2.0 工程验收报告

## 范围

本轮按用户要求零模型费用。交付完整的可运行Agent主链路：数据→标签/标注接口→工具循环→词法检索→证据报告→本地Web→恢复与评测。真实模型效果、人工金标和正式盲测是独立验收项，当前未完成。

## 尚未验证

正式200–400条人工复核数据、40题真实任务盲测、40条独立检索测试查询、相关性/情绪Macro-F1≥0.80目标、引用语义支持率≥0.95目标、真实模型任务成功率≥0.80目标均待验证；原门槛未降低。没有分类F1、真实成本下降、生产吞吐等可填写结果。

## 负结果与取舍

检索简单合成集没有证明优于子串，故暂不增加embedding/rerank依赖。TF-IDF centroid仅为可复现分类基线，不冒充原计划中的LinearSVC。工具数字和引用存在性校验不能证明对用户问题的完整语义回答；真实任务仍须人工rubric。没有预算时继续交付工程，不自动制造金标或用模型自评分填补验收。
