# MetroInsight Agent

面向公共交通服务分析的证据型 AI Agent 项目，目标是形成可运行、可评测、能在面试中讲清楚的 AI 应用作品集。

**当前状态：2026-10-16 已完成接手审查、岗位调研、开源项目核验和改造规划。新版 Agent 尚未实现。** 现有 `platform/` 是历史原型，不能按新版设计介绍为已完成功能。

## 项目将解决的问题

用户用自然语言提出分析任务，例如：“比较这批上海地铁反馈中的拥挤与延误问题，提供原文证据，并标出样本不足的线路。”系统将解析范围，调用结构化统计与证据检索工具，必要时补查资料，输出可追溯的分析报告，同时显示执行步骤、失败情况和资源消耗。

旧版的文本分类、事件抽取、图片识别和领域标签是可复用资产。新版重点补齐工具调用、检索、事实与数字校验、持久状态、错误恢复、评测及服务交付。

后续采用 `src/metro_agent/` 建设新版。迁移前保留历史目录；首次任务是恢复可复现环境与离线基线。

## 当前可验证的内容

审查快照及复现结果见 `docs/audit/2026-10-16/summary.json` 与 `smoke.json`。完整文件索引在同目录的 `inventory.csv`，它包含本地环境路径，不作为公开作品集材料。

当前只有离线读取、辅助函数、内存数据库和 HTML 渲染检查；没有重新执行在线采集、真实 LLM 分类或 OCR，不能据此宣称分类准确率或线上可用性。

原始数据、作者信息、报名联系方式、登录态、模型密钥和旧生成报告不应直接进入公开仓库。第三方代码的来源与许可见 GitHub 学习清单；本项目尚未初始化根 Git 仓库，也没有发布网站或上传 GitHub。
